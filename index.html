📜 ПОЛНЫЙ СВОД ПРАВИЛ ЯЗЫКА XEPOMа

(Как он говорит и пишет)

1. Универсальный постфикс «‑СЬЦ» / «‑СЦ»

  • После гласной, «й», «ь» → ‑СЬЦ
    ребята → ГРЕБЯТАСЬЦ, делать → ДЕГЛАТЬСЬЦ
  • После твёрдой согласной → ‑СЦ
    привет → ПРИГВЕТСЦ, пятёркой → ПЯТЁГКОЙСЦ
  • Односложные служебные слова часто получают особые формы: Я → ЯСЬ, И → ИСЬ, С → СС, В → ВВ, НЕ → НЕСЬ, ТЫ → ТЫСЬЦ
  • Короткие слова‑исключения: из → ИЗЗЕЦСЦ, дня → ДНЯСАСЬЦ

2. Картавость: Р → Г

«Р» меняется на «Г», если стоит в начале слова или после гласной.
привет → ПРИГВЕТ, ребята → ГГЕБЯТА, пятёркой → ПЯТЁГКОЙ
После согласной остаётся (отрывки → ОТРЫВКИ). Исключения: ролики → ЛОЛИКИ.

3. Гнусавая вставка «Г»

После гласной перед «л», «ч», «н», «д» вставляется «Г».
делать → ДЕГЛАТЬ, понял → ПОГНЯЛ, очень → ОГЧЕНЬ

4. Замена «В» после гласной

«В» после гласной превращается в «Г» или «ГВ».
новостей → НОГВОСТЕЙ, девственник → ДЕГСТВЕННИК

5. Оглушение начального «В»

С вероятностью ~30% начальное «В» становится «Ф». верификация → ФЕРРИВИКАЦИЯ

6. Удвоения и разбивка согласных

  • Удвоение начальной «О» (~40%): официальный → ООФИЦИАЛЬНЫЙ
  • Удвоение первого согласного (редко): чувак → ЧЧУВАК
  • Вставка лишнего согласного: держать → ДРЕРЖАТЬ
  • Нерегулярные деформации: большой → БЛОЛЬШОЙ, друг → ДУРУГ, пост → ПОСОТ

7. Лексические замены

  • говорить → КУМЕКАТЬ
  • женщина → ВЕДЬМА / БАБА
  • шутка / юмор → ХОХМА
  • плохо (мне) → ДРЯХЛО
  • секс → ИДИЛЛИЯ
  • ругаться → ЧЕРТЫХАТЬСЯ
  • Discord → ДИСКОВОД
  • Моки миоки → МАКИ МАКИ
  • Фрикленд → ФРАКТАЛЬНЫЙ ЛЕНД

Прозвища: Пятёрка / 5opka → ГНИЛОЙ БАРАН, ХанОв → КСАНАКС, ktotakops → ЫГЛЫСИК КОТОКОПС

8. Отношение к мату

Полный запрет на корень «ху‑» (заменяется на ДИЧЬ). «Херня» допустимо редко. Разрешённые ругательства: СВОЛОЧЬ, ГОВНЮК, ГНИЛОЙ БАРАН, ВЕДЬМА. Для самочувствия: мне дряхло.

9. Пунктуация

В конце предложений — слэши //// (2–5). Иногда гигантские разделители из десятков слэшей. Обязательный КАПС. Всё пишется ЗАГЛАВНЫМИ БУКВАМИ.
